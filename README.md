# DualSub モバイル

iPhone の Safari を中心に、YouTube の英語ポッドキャストを英文・和訳・単語の意味と一緒に見る静的ページです。YouTube IFrame Player API でネットから再生し、動画をダウンロードしません。字幕は YouTube から取得せず、Gemini に動画の区間を渡して書き起こし・和訳を作ります。ビルド工程、npm 依存、service worker はありません。

## 使い方と API キー

1. [Google AI Studio](https://aistudio.google.com/) で、**課金なしの無料枠プロジェクトの Gemini API キー**を作ります。課金を有効にしたプロジェクトのキーを使わないでください。無料枠の利用可否・上限はアカウントやモデルによって異なります。
2. [Google Cloud Console の認証情報](https://console.cloud.google.com/apis/credentials)でそのキーを選び、API の制限を「キーを制限」→ **Generative Language API だけ**にします。アプリケーションの制限は「ウェブサイト（HTTP リファラー）」にして、配置先のドメイン、例えば `https://YOUR-NAME.github.io/*` を許可します。localhost で確認する間だけ `http://localhost:8080/*` も追加してください。このページは別オリジンへはドメイン部分のみをリファラーとして送るため、リポジトリのパスだけを許可すると403になることがあります。[Google Cloud のキー制限の説明](https://docs.cloud.google.com/docs/authentication/api-keys)も参照してください。
3. ページの「設定 · Gemini API」にキーを入力して保存します。既定モデルは `gemini-3.5-flash-lite`、予備は `gemini-3.1-flash-lite`。利用できるモデルに必要に応じて変更してください。以前の既定モデルの組み合わせは新しい組み合わせへ移行し、それ以外の保存済み設定は維持します。
4. YouTube URL を貼り付けて「動画を開く」を押します。watch、youtu.be、m.youtube.com、shorts、live の URL に対応します。再生ボタンは必要に応じて手で押してください。
5. 初回は現在位置から120秒、その後240秒ずつ翻訳します。停止中・再生前は現在位置を含む未訳の区間だけを作り、再生中は訳済みの残りが150秒を切ったら1区間を作ります。次の訳済み区間との間に15秒未満の隙間が残る場合は、その開始位置まで今回の区間を延ばして一緒に送ります。動画の末尾など、それでも残る15秒未満の区間は保存せず、この画面の間だけスキップします。通常は末尾20秒を余分に読み、境目の文を次へ引き継ぎます（動画の終わり・次の訳済み区間を超えません）。送信する開始は切り捨て、終了は切り上げた整数秒です。語数が区間秒数×0.8未満、または最初の文が30秒以上遅い場合は1回だけ取り直し、採用語数の多い結果を使います。取り直しが失敗しても初回に採用できた文は残します。発話なしでも取り直しは1回までです。
6. 文をタップするとその先頭へ移動します。「もう一度」は今の文の0.5秒手前へ戻り、文の切替から1.5秒以内で前の文の頭が現在位置から30秒以内なら前の文へ戻ります。「精聴」で文ごとの再聴・自動送りを使えます（下記）。「和訳OFF」は各文の和訳を隠し、単語注釈は残します。指でスクロールすると5秒間は自動追従を止めます。対応端末では再生中に Wake Lock を使い、画面消灯を抑えます。

## 精聴モード

操作行の「精聴」をオンにすると、今の文を指定回数聞き、終わると自動で次の文の頭へ進みます。「回数」は1〜5（既定3）、「間」は0 / 0.5 / 1 / 1.5 / 2 / 3 / 5 / 10秒（既定1.5）。精聴オン・オフ、回数、間はこのブラウザの localStorage に保存します。設定変更時はカウントをやり直します。旧「1文停止」は精聴へ置き換えました。回数1でも、間をあけて次の文へ自動で進みます。

文末は、次の文の開始0.2秒手前で推定します。字幕の塊の終わり・動画の終わりがそれより早ければそちらを使います。最後の文に次の開始時刻がない場合は訳済み区間の終わりか動画の長さを使います。再生速度で割った残り時間のタイマーで止め、再生・一時停止・速度変更・シークで張り直します。各回の後で「間」の秒数待ち、同じ文の頭から再生します。指定回数聞いたら同じ間隔をあけて次の文へ進み、次の文はカウントを0から始めます。

状態欄の近くに「精聴 2/3 回目」「次まで 1.5秒」などを表示します。文のタップ、「もう一度」、精聴をオンにする操作、想定位置から2秒以上ずれるシークでカウントがリセットされます。YouTubeの再生ボタンで自分で一時停止した場合は、文末・待機のタイマーを取り消し、勝手には再生しません。再び再生するとその位置から精聴を続けます。精聴をオフにしても、すでに止まっている動画を勝手に再生しません。

Safariがユーザー操作なしの再生を拒否した場合、3.5秒たっても再生を確認できなければ自動処理を止め、「タップで続ける」を表示します。このボタンをタップして再開してください。動画の最後は停止したままです。次の字幕がまだない場合は停止して字幕を待ち、届いたら次の文へ進みます。翻訳のエラー・上限・一時スキップの制限に達した場合は、そちらの状態表示に従って再開・シークしてください。

YouTube は再生直後まで長さを0と返す場合があります。取得できた長さは字幕キャッシュ・バックアップにも保存し、再生前に0ならキャッシュの長さを使います。キャッシュにも長さがなければ現在位置から120秒を採用範囲にし、さらに末尾20秒を余分に指定して翻訳します。長さ0を理由にシーク位置を0へ切り詰めません。長さが不明のまま再生中になった場合だけ、長さ確認中・ライブ配信非対応の表示を出して次の翻訳を待ちます。[YouTube の getDuration リファレンス](https://developers.google.com/youtube/iframe_api_reference#Retrieving_video_information)を参照してください。

初回に採用文が0件で、取り直しが失敗またはすべて範囲外だった場合は、無音の区間として保存しません。通信・上限エラーはそれぞれの再開処理に回し、未完了・範囲外などは10秒後に1回、その後は画面が表に戻ったときに1回取り直します。正常な応答でも採用文が2回続けて0件なら、この画面の間だけスキップして先へ進みます。空応答・スキップを永続キャッシュに混ぜません。

訳した区間・最近見た動画・再生位置は動画ごとに localStorage に保存します。再生位置は字幕と別キーなので、10秒ごとの保存で字幕全体を書き直しません。キャッシュがある区間は再取得しません。URL の `?v=<動画ID>&t=<秒>` は約10秒ごと、および文タップ・画面を離れる際に更新します。容量不足時だけ削除候補を調べ、古い動画の字幕・位置から消します。API キーとモデル設定も localStorage にだけ保存します。キーは Gemini への HTTPS リクエストの `x-goog-api-key` ヘッダに送信し、ページ URL・コード・字幕キャッシュには含めません。キーを削除したい場合は欄を空にして保存してください。

503 / 500 は5秒、15秒待って再試行し、その後予備モデルを試します。すべて失敗した場合は60秒待って最大3回自動再開し、残り秒数を表示します。1回の通信は応答本文の受信まで含め180秒で打ち切り、通信エラーとして扱います。通信エラーは10秒後に1回、その後も失敗した場合は画面が表へ戻ったときに1回再試行します。429 は応答の quotaId と retryDelay だけを使い、分上限なら指定秒数（情報不足なら60秒）待って再開、日上限・判定不能なら停止して再開ボタンを表示します。日上限は短い retryDelay があっても停止します。API のエラー本文は表示しません。[Gemini の上限の説明](https://ai.google.dev/gemini-api/docs/rate-limits)を参照してください。

STOP 以外の終了理由は区間を半分に割って1回試します。それでも作れない半区間は「作れなかった区間」としてこの画面の間だけ飛ばし、後の区間を作ります。停止中・再生前は、最初に飛ばした区間より先でも失敗したら、それ以上先へ進みません。シークまたは再生でこの制限を解除します。このスキップ情報は保存・書き出しせず、再読み込みで再度試せます。400 の動画アクセス不能は専用メッセージ、その他の400 / 401 / 403 はキー・権限・設定、404 はモデル名を確認します。手動再開・設定保存は通信・混雑の自動再試行回数をリセットしますが、停止中の区間スキップ制限は解除しません。状態欄の「今日の送信」は端末のローカル日付で実際の送信回数（取り直し・再試行も含む）を数えます。Google の残り枠ではありません。

## 字幕のバックアップと保存領域

設定の「字幕を書き出す（JSON）」で保存済み全動画と現在の動画の字幕をまとめて保存できます。API キー・モデル設定・再生位置・一時スキップは含めません。「字幕を読み込む」で復元し、既存の字幕と結合します。既存の訳済み区間の端から8秒以上内側では既存の文を優先し、取り込み文を追加しません。区間の端と未訳の範囲では結合します。別端末へ移す場合も使えます。保存容量が足りない場合は一部を永続保存できない旨を表示します。

Safari では、そのサイトを操作しないままSafariを使った日が7日続くと localStorage などが削除される場合があります。**ホーム画面に追加して、そのアイコンから使うことをおすすめします。** ホーム画面のWebアプリはこの7日制限の対象外で、Safariとは保存領域も分かれます。ただし手動削除・端末の容量不足などに備え、定期的に字幕を書き出してください。[WebKit の保存領域・ホーム画面アプリの説明](https://webkit.org/tracking-prevention/)に基づきます。

GitHub Pages の `https://YOUR-NAME.github.io/REPO-A/` と `/REPO-B/` は同じオリジンです。同じアカウントの全ページが localStorage を共有し、別のリポジトリのスクリプトもこのキー・字幕を読み取れます。HTTP リファラーの制限もドメイン単位なので、信頼できるページだけを同じドメインで運用してください。パスごとにキーを隔離したい場合は異なるドメインで配置する必要があります。

## ファイル

- `index.html` — 入力画面、設定、プレーヤーと字幕リストの枠。
- `app.js` — DOM、YouTube プレーヤー、先読み制御、状態表示、保存。
- `lib/core.js` — URL・時刻・区間・字幕・注釈・キャッシュの純粋ロジック。
- `lib/listening.js` — 精聴の文末・再聴回数・待機・再生確認の純粋な状態遷移と設定保存。
- `lib/gemini.js` — Gemini リクエスト、応答解析、再試行、予備モデル。
- `style.css` — モバイル表示、上部固定プレーヤー、ライト／ダーク配色。
- `manifest.webmanifest` — ホーム画面追加用の最低限の設定。
- `icon.svg` — アプリアイコン。
- `test/` — Node 標準のテストランナーで動く検証コード。
- `README.md` — 使い方・配置・制限。

## ローカルでの確認

Node.js があれば npm install は不要です。このフォルダで次を実行します。

```powershell
node --test test/
```

`file://` では YouTube の埋め込みが動かないので、HTTP で開きます。次のコマンドは、このフォルダのファイルを `127.0.0.1:8080` で配信します。PowerShell 5.1 でそのまま実行できます。

Windows PowerShell 5.1 で引用符を正しく渡すため、`--%` を使用します（コマンドは1行で入力）。

```powershell
node --% -e "const http=require('node:http'),fs=require('node:fs'),path=require('node:path'),root=process.cwd();http.createServer((req,res)=>{let p;try{p=path.resolve(root,'.'+decodeURIComponent(new URL(req.url,'http://localhost').pathname));}catch{res.writeHead(400).end();return;}if(p!==root&&!p.startsWith(root+path.sep)){res.writeHead(403).end();return;}if(p===root)p=path.join(root,'index.html');const types={'.html':'text/html; charset=utf-8','.js':'text/javascript; charset=utf-8','.css':'text/css; charset=utf-8','.svg':'image/svg+xml','.webmanifest':'application/manifest+json'};fs.readFile(p,(err,data)=>{if(err){res.writeHead(404).end();return;}res.setHeader('Content-Type',types[path.extname(p)]||'application/octet-stream');res.end(data);});}).listen(8080,'127.0.0.1',()=>console.log('http://localhost:8080'));"
```

ブラウザで `http://localhost:8080` を開き、停止は Ctrl+C。iPhone の実機では GitHub Pages などの HTTPS 配置先を使います。実ブラウザ・実 API の検証は別途行ってください。

## GitHub Pages へ置く

1. GitHub にリポジトリを作成し、このフォルダのファイル一式を公開用ブランチに追加します。実際の API キーはファイルに書かず、アップロードしません。
2. リポジトリの Settings → Pages → Deploy from a branch を選び、公開ブランチと `/ (root)` を指定して保存します。
3. 表示された HTTPS URL を Safari で開きます。リポジトリ名のサブパスでも、ファイル参照は相対パスなので動作します。
4. Safari の共有 →「ホーム画面に追加」。キー・キャッシュは端末とブラウザごとなので、その画面でも必要に応じて設定します。

この実装作業では公開操作を行いません。

## iPhone の YouTube アプリから開くショートカット

例として配置先を `https://YOUR-NAME.github.io/YOUR-REPO/` とします。

1. 「ショートカット」アプリで新規ショートカットを作り、詳細で「共有シートに表示」を有効にします。受け入れる種類は URL とテキスト。
2. 「入力から URL を取得」を追加し、入力を「ショートカットの入力」にします。次に「リストから項目を取得」で最初の URL を取り、「入力からテキストを取得」で文字列にします。
3. 「テキストを一致」で以下の正規表現を指定します。watch の v パラメータ、短縮 URL、shorts、live を対象にします。

   ```text
   (?i)(?:[?&]v=|youtu\.be/|youtube\.com/(?:shorts|live)/)([A-Za-z0-9_-]{11})(?=[?&#/]|$)
   ```

4. 一致がない場合は「アラートを表示」で「YouTube URL が見つかりません」と表示して終了します。一致があれば「リストから項目を取得」で最初の一致を選び、「一致したテキストからグループを取得」でグループ1を取り出します（アクション名は iOS の版で多少異なります）。
5. 「テキスト」に `https://YOUR-NAME.github.io/YOUR-REPO/?v=` を入力し、その末尾にグループ1の変数を挿入します。
6. 「URL」→「URL を開く」に渡します。Safari を既定ブラウザにしておきます。
7. YouTube アプリで動画の「共有」→「その他」→このショートカットを選びます。`t` がないため、この動画のキャッシュに記録された位置から再開します。

このページ自体は YouTube ホストのみを許可します。ショートカットには YouTube アプリから共有した URL を渡してください。

## 既知の制限

- Gemini の書き起こし・訳・単語注釈には欠落や誤りがあり、時刻もずれることがあります。公式字幕ではありません。重複は、新しく来た文と既存の文だけを区間境界・字幕の塊の継ぎ目の±8秒で比べ、文同士の時刻差8秒以内・短い方が4語以上で、その語の8割以上を含むときに判定します（重複語を数えた共通語数÷短い方の語数）。長い英文と早い先頭時刻を残します。同じ応答内の繰り返しや先頭3秒の本物の文、4語未満の短い発話は除去しません。継ぎ目近くの長い文の本物の繰り返しを統合する可能性は残ります。
- 非公開・年齢制限・地域制限などの動画は Gemini が読めないことがあります。埋め込み禁止はエラーと YouTube リンクを表示します。ライブ配信は対象外です。
- iOS の自動再生・バックグラウンド再生・速度変更は YouTube / Safari の制約を受けます。全画面再生では字幕リストは同時表示できません。
- 最小限の manifest と SVG アイコンのみなので、iOS の版によってホーム画面アイコンが独自の画像になることがあります。オフライン再生には対応しません。
- localStorage はプライベートモード・設定・容量不足で使用できない場合があります。その場合も画面内の翻訳は続けられますが、永続保存は保証できません。Safari とホーム画面版で保存領域が共有されない場合があります。
- API キーはこの配信元のブラウザ保存領域に平文で保存されます。自分の端末と信頼できる配置先で使い、共有端末では削除してください。拡張・第三者スクリプトによる読み取りまでは防げません。
- シーク中に送信済みのリクエストは完了まで待ち、その次に未翻訳のシーク先を優先します。同時に送るリクエストは常に1本です。精聴の文末は推定なので、発話の末尾が切れることがあります。文末タイマーもSafariのバックグラウンド制限やYouTubeの応答遅延の影響を受けるため、画面を開いたまま使ってください。
- 無料枠のリクエスト数が少ないため、長い動画を連続して使うと上限に達します。ネットワーク障害・Gemini のモデル提供状況にも依存します。
- キャッシュされた誤訳を画面上で編集する機能はありません。書き出した JSON を編集して別環境へ読み込むことはできます。サイトデータの削除はキー設定も消すので、事前にバックアップしてください。
